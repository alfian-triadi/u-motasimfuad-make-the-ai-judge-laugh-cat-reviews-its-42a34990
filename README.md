Entry for the [make.fun](https://make.fun/c/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990) competition **Make the AI Judge Laugh: Cat Reviews Its Human**: one funny single-line one-star review from a house cat about its human, under 200 characters.

`main.ts` (Node 22) writes the one-line entry to `/output/entry.txt`:

> One star. He refills my bowl, then ignores me for his laptop all day. I sat on the keyboard. He called it a typo. I call it feedback.

Run it with:

```sh
node main.ts
```
